# Short Project Explanation 
-AI Gym Assistant is a Streamlit-based web app that generates personalized workout plans using AI.
-It considers user inputs like age and fitness goals and many more info necessary to create structured, safe training guidance.

# problem it solves
-Many beginners don’t know how to create effective and safe workout plans.
This app provides instant, AI-generated guidance while ensuring age-based safety checks to prevent inappropriate training recommendations.
-It gives a perfect time table for your diet and excercise for a week that really suits u and only u 


# AI Gym Assistant

An AI-powered gym workout planner built using Streamlit and Groq API.

## 🚀 Features
- Personalized workout plan
- Age-based safety warnings
- Simple user interface
- AI-generated fitness guidance

## 🛠️ Tech Stack
- Python
- Streamlit
- Groq API
- Git & GitHub

## 📦 Installation

1. Clone the repository
2. Install dependencies:
   pip install -r requirements.txt
3. Add your GROQ_API_KEY in .env
4. Run:
   streamlit run app.py

## 🔐 Environment Variables

1.create a '.env' file and add :
GROQ_API_KEY = your_api_key_here
